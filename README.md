# D’Lice — Landing Page

Landing page responsif untuk D’Lice dengan katalog menu, filter kategori, form pemesanan WhatsApp, informasi lokasi, dan media sosial.

## Menu
- Es Buah Premium
- Cadbury Braid Cheese
- Cadbury Kunafa Pistachio Braid

## Menjalankan
Website statis; deploy ke Vercel dengan preset Other, tanpa build command, output directory `.`.

## Catatan aset
Foto produk menggunakan foto unggahan pemilik yang diletakkan di folder `assets/`. Harga belum ditampilkan karena harga resmi belum diberikan.
